# 🎸 Violão de Bolso

Violão interativo pra aprender do zero: braço com os dedos animados, play-along com faixa de acordes, curso em módulos, biblioteca de acordes, treino de troca e vídeo do YouTube de cada música.

Músicas: Domingo à Noite, Coração Partido e Bom Marujo (VMZ), Só os Loucos Sabem (Charlie Brown Jr.), Talking to the Moon (Bruno Mars) e Die With a Smile (Lady Gaga & Bruno Mars).

👉 **Abrir:** https://matheusdssantos.github.io/violao-de-bolso/
